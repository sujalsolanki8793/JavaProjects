# Hotel Management System

## Project Overview

Hotel Management System is a Java console-based application developed to manage hotel room bookings and restaurant food orders.

The system allows users to:

* Book Single or Double Rooms
* Select Room Types
* Calculate Room Booking Costs
* Order Food from Different Cuisines
* Calculate Food Bills
* Exit the System

## Features

### Room Booking

* Single Room Booking
* Double Room Booking
* Regular Size Bedroom
* King Size Bedroom
* Automatic Cost Calculation

### Restaurant Management

* South Indian Cuisine
* Italian Cuisine
* Punjabi Cuisine
* Chinese Cuisine

### Billing

* Calculates total room booking cost
* Calculates total food order cost
